# Gokulakannan (RootGokul-404) Portfolio — Design Direction

## Overview
A clean developer notebook translated into an interactive web portfolio: terminal-green accents, technical annotations, structured cards, and generous spacing. Designed to showcase engineering skills, backend systems, and mini projects with clarity and precision.

## Chosen Design Approach — Terminal Field Notes

### Design Movement
**Technical developer notebook and clean systems interface.** The site uses structural typography, clear hierarchy, and dark mode aesthetics with focused neon accents to create a modern developer identity.

### Core Principles
1. **Signal over spectacle:** Neon green (#C7FF40) is used as an accent for active states, key skills, and primary actions.
2. **Clear structure:** Structured cards and clean typography for projects, skills, and timeline.
3. **Systems mindset:** Clear labels, status indicators, and clean code presentation.
4. **Work-focused:** Practical projects and code repositories take center stage.

### Color Palette
- **Background:** `#080c0a` (Deep Slate / Dark Base)
- **Cards & Surfaces:** `#0c120f` with fine `#ffffff10` borders
- **Primary Accent:** `#C7FF40` (Signal Green)
- **Secondary Accent:** `#22d3ee` (Cyan)
- **Text:** `#f1f5f9` (Light Slate) and `#94a3b8` (Muted Slate)

### Typography
- **Headings:** Space Grotesk
- **Code & Labels:** IBM Plex Mono / Monospace
- **Body:** Inter / Clean Sans
